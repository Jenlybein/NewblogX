# ADR-0034：合规自动拒与两种拒后落点

- 状态：已交付
- 日期：2026-11-08
- 来源：parent spec [#302](https://github.com/Jenlybein/NewblogX/issues/302)（发布治理一期）· 落地票 [#313](https://github.com/Jenlybein/NewblogX/issues/313)（自动拒与落点）· 上游 [#312](./0033-risk-models.md)（合规判定）· 决定过程见 [grill 记录 §4.4 / §五](../notes/2026-11-07-publish-gate-and-moderation-grill.md)

## 背景与问题

第③层已经能产出 `clean / suspect / violation` 的结论，但结论本身不改变任何东西——一篇明确违规的文章照样躺在公网上等管理员有空才处理。#313 要把结论变成一个**动作**，同时回答三个问题：

1. **拒掉之后文章落在什么状态？** 落草稿、落已拒绝，还是两件不同的事？
2. **怎么让管理员知道"这是我拒的还是系统拒的"？** 系统拒是不通知、还是留痕？
3. **配额怎么算？** 自动拒发生在提交之后，会不会变成一次提交扣两次额度？

## 决策

1. **落点分成两种，按原因分配**：
   - **质量不达标 → 草稿**（ADR-0032 已定）。含义是"还差几分"，作者改一改就能过。
   - **合规命中 → 已拒绝**，并留一条**待处理**审核任务。含义是"这篇东西不该在这"，静静沉在草稿里没人会再看到它。
2. **自动拒只对"高置信"生效**：`verdict == violation` 且 `risk_level ≥ 2`。`suspect` 一律交人——误判会直接落到作者身上，而作者没有申诉渠道。
3. **只有「审核中」与「已发布」会被自动拒**。草稿不拒（还没出去过，作者自己改就行，拒了反而更难恢复）；已拒绝不重复处理（同一篇文章创建与发布各判一次，第二次是空操作）。
4. **审核任务来源单列一个值 `compliance`**。复盘时必须一眼分清"人拒的"与"系统拒的"，否则自动拒的误判会被算成审核员判断失误。
5. **作者只看到枚举文案，看不到任何模型细节**。"内容不合规"来自固定枚举；类别、依据、命中词一律不出现在面向作者的响应里。
6. **通知在缺少驳回原因时兜底到合规文案**：自动拒的任务仍是待处理（没有驳回原因可读），通知不能出现"理由："后面空白。兜底读的是风险记录里的档位，只用来选固定文案，不携带细节。
7. **配额不重复扣**：提交时预占过一次，自动拒是异步副作用，不再预占（验收标准 3）。

## 理由与已否决方案

- **否决"合规也落草稿"**：草稿列表是作者的工作台，一篇明确违规的稿子混在里面既不会有人看，也不该被作者继续"小修小补"再投一次。
- **否决"自动拒把任务也标成已拒绝"**：那样文章虽然拒了，管理员在"待处理"里看不到它，等于系统单方面做了决定且不告知——这与"合规判定的处置权在人"相冲突。
- **否决"只按 violation 不看级别"**：档位已经三档，不再区分级别会让一条措辞可疑的稿子直接进"已拒绝"，恢复成本远高于先看看到底怎么回事。
- **否决"已发布文章不撤"**：那自动拒在最常见的场景（站点默认跳过审核）里永远不生效——投稿即发布，判定到达时文章已经在公网上了。
- **否决"自动拒时再扣一次配额"**：一次提交扣两次额度，作者会莫名其妙地少掉一半机会。
- **否决"给作者看模型依据"**：等于公开判定规则，等于教人绕过（与 ADR-0033 决策 7 同一条理由）。

## 代价 / 不做什么

- **误判不可申诉**：自动拒没有申诉入口，作者只能改稿重投。
- **待处理任务会"堆积"**：自动拒的任务是待处理状态，但对应文章状态是已拒绝，管理员点"通过"会撞上状态机（只有审核中可审）。这一批任务的实际处置是"看一眼、删掉/关闭"，不是真正的审核队列。
- **通知是固定文案**：作者只能知道"不合规"，不知道为什么。
- **不做词表自动拒**：阻断级词表仍然只标红（#311 的范围），自动拒只对模型结论生效。
- **不做批量撤销/恢复**：没有"把被自动拒的文章批量改回草稿"的工具。

## 当前生效约束

1. **高置信门槛固定为 `violation` + `risk_level ≥ 2`**，放宽到 suspect 等于把误判直接推给作者；要改必须重新评估申诉成本。
2. **两种落点不得合并**：质量 → 草稿，合规 → 已拒绝 + 待处理任务。
3. **自动拒不得二次预占配额**。
4. **面向作者的响应不得包含模型类别/依据/命中词**；唯一可见的是枚举文案。
5. **`source=compliance` 必须保留**，不得为了省一个枚举值复用到 `create`。
6. **草稿不被自动拒**，这一点不得为了"更严格"而改。
