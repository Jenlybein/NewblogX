# ADR-0031：首屏指针尾迹可切换——默认像素尾迹（自实现），后台可切回指针墨流

- 状态：已交付
- 日期：2026-11-13
- 来源：产品口径（用户："像素尾迹替代首屏烟雾尾迹；后台加装饰设置可切回；默认像素尾迹；不要用他的包"）

## 背景与问题

首屏封面（ADR-0011 的编辑部例外区）在 2026-11-10 把装饰层换成了「指针墨流」（WebGL 流体）。它
在暗墨底上晕开的观感偏"烟"，和整站"果冻盒"的硬边、像素、色带语言不是一路。用户要换成
reactbits.dev/animations/pixel-trail 那种**像素方块尾迹**，但不接受直接引第三方包，并要求后台
能切回原来的墨流、默认用像素。

两套效果都是"指针划过时的纯装饰"，切换只影响观感，不影响任何功能；因此它属于装饰配置段
（`deco`，ADR-0014 的运行时配置），而不是站点主题或功能开关。

## 决策

1. **`deco.home_trail` 两个值**：`pixel`（默认）与 `smoke`。缺键 / `null` / 未知值一律按
   `pixel` 处理（读者站与后台两侧同样的回落口径），所以老配置（没有这个键）行为不变。
2. **像素尾迹自己实现，不引第三方包**：
   - 尾巴由若干「追着指针跑」的墨点组成，越靠后跟得越慢；
   - 每个结点按网格坐标盖章，位置带轻微随机抖动 → 方块边缘参差；
   - 每格有寿命（约 700ms）逐帧淡出；外圈大而淡 + 内圈小而实两层绘制模拟辉光
     （不用 `shadowBlur`：每格一次模糊在快速甩动时会掉帧）。
3. **颜色只从 token 读**：默认 `--jelly-yellow`，与首屏黄色色带同一支；组件与合成器里不写任何
   色值。换主题 / 换 token 不需要改实现。
4. **切换由读侧配置驱动**：首页从站点 store 的 `deco.home_trail` 计算模式；SSR 阶段配置还没到
   手时按默认 `pixel` 渲染。后台「装饰」页提供一个单选（像素尾迹 / 指针墨流），保存写整段
   `deco` 段（与其它装饰参数同一套读-改-写）。
5. **两套效果共用同一个图层位**：都挂 `.home-cover__ink`（绝对定位、z-index 1、`pointer-events:
   none`、`aria-hidden`）；`HomePixelTrail` 与 `HomeInkFluid` 互斥渲染。
6. **同样的动效纪律**：`prefers-reduced-motion: reduce` 下像素层不挂监听、不画帧；标签页隐藏 /
   画布离屏 / 无存活方块且指针静止时停 rAF，不留常驻循环。

## 理由与已否决方案

- **否决「直接引 ReactBits / 它的 npm 包」**：用户明确不要第三方包；而且它绑定 React + framer-motion，
  与本仓库的 Vue/Nuxt 技术栈和动效门禁（弹簧参数只能来自 `SPRING_*`）冲突。
- **否决「用 DOM 方块复制原效果」**：一次甩动上百个节点，布局与样式计算都在主线程，首屏会掉帧；
  canvas 只有一张位图。
- **否决「把像素层也做成 WebGL」**：两套 GPU 代码要各自维护降级与上下文丢失，收益只是"统一"。
- **否决「把切换做成站点主题 / 构建期开关」**：它只影响观感，应该跟其它装饰参数一样，运营可以
  改完即时生效、不用重新构建镜像。
- **否决「默认继续用墨流、像素作为可选」**：用户明确要求默认像素。

## 当前生效约束

- `deco.home_trail` 只接受 `pixel` / `smoke`；其它值一律按 `pixel`，读者站与后台两侧回落口径必须一致。
- 像素尾迹的跟随必须是弹簧（参数只能来自 `SPRING_TRAIL` / `SPRING_TRAIL_TAIL`），不得退回一阶 lerp
  （lerp 没有惯性与弹性，快速甩动会顿挫）。
- 像素尾迹的颜色只能来自 CSS token（默认 `--jelly-yellow`），不得出现色值字面量。
- 像素尾迹必须是纯装饰：`pointer-events: none`、`aria-hidden`、不进 Tab 序列、不接管任何点击。
- `prefers-reduced-motion: reduce` 下不得挂监听、不得画帧；隐藏 / 离屏 / 静止时必须停 rAF。
- 两套尾迹共用 `.home-cover__ink` 的图层位与 z-index，切换不得改变首屏图层顺序。
