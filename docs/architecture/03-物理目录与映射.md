# 03 · 物理目录与文件映射

> 回答两个问题：**新代码放哪**、**现有 83,000 行去哪**。
> 关键变化：取消 monorepo，拆成 `backend` / `frontend` / `frontend_admin` / `deploy` 四个解耦目录。

## 1. 顶层：四个解耦目录（取消 monorepo）

> 仓库根**不再有 `pnpm-workspace.yaml` / `turbo.json` / `packages/`**。三部分各自 `go.mod` / `package.json` 自洽，唯一的耦合点是后端自动生成的 `openapi.json` 契约。

```
blogx/                              ← 仓库根（无 workspace / 无 turbo）
├── backend/                        # Go 后端（原 apps/api）
│   ├── cmd/
│   │   ├── server/main.go          # ★ 唯一合成根
│   │   └── cli/                    # 原 flags/（运维命令）
│   ├── internal/                   # 垂直模块（article / comment / ... / platform）
│   ├── tools/archcheck/            # ★ 新建：AST 架构规则（替代 scripts/arch_guard.ps1）
│   ├── testkit/                    # ★ 测试基建
│   ├── go.mod                      # module myblogx（保持不变）
│   ├── openapi.json                # ★ 生成产物（swag init），CI 校验生成一致性
│   └── Makefile                    # make openapi / make test / make build
│
├── frontend/                       # Nuxt 读者站（原 apps/web）
│   ├── server/routes/api/[...path].ts   # 唯一代理入口（→ $API_BASE_URL）
│   ├── src/api/generated/api.gen.ts     # ★ openapi-typescript 生成，禁止手改
│   └── package.json                # 自洽，不引用 sibling 包
│
├── frontend_admin/                 # Nuxt 管理后台（原 apps/admin）
│   ├── server/routes/api/[...path].ts
│   ├── src/api/generated/api.gen.ts
│   └── package.json
│
├── deploy/                         # 基础设施（不属于任一 app）
│   ├── compose/{local,production}/docker-compose.yml
│   ├── docker/{api,web,admin,nginx,...}
│   └── nginx/
│       ├── nginx.template.conf     # ★ 4 份合并为 1 模板 + envsubst
│       └── envsubst.sh
│
├── .github/workflows/ci.yml        # ★ 新建（当前完全没有）
├── docs/architecture/              # 本文档
└── README.md
```

**净删除约 8,000 行源码 + 2.1 MB 二进制 + monorepo 配置，并消除一处 git 历史包袱（重建仓库）。**

### 4.3 类型自动生成（替代 `packages/shared-types`）

每个前端各自跑：

```bash
# 在 backend/ 生成契约
cd backend && make openapi        # swag init → backend/openapi.json

# 在每个前端各自生成类型（不共享代码）
cd frontend        && pnpm openapi-typescript ../backend/openapi.json -o src/api/generated/api.gen.ts
cd frontend_admin  && pnpm openapi-typescript ../backend/openapi.json -o src/api/generated/api.gen.ts
```

- 生成的 `api.gen.ts` **禁止手改**，CI 校验"生成结果与提交一致"
- 手写类型只允许纯前端状态（UI props、本地枚举）
