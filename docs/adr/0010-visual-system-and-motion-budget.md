# ADR-0010：双前端视觉系统与动效预算（五色锁死、圆角归零、档位 B）

- 状态：已取代（by [ADR-0012](./0012-neutral-glass-visual-system.md)）
  被取代的是色相集合与主色、圆角政策、结构线规则、形状语义、动效档位（"档位 B"）与顶栏非吸顶；**继续有效的是**：两层 token + 单一颜色来源、暗色为同一组语义 token 的第二份取值、强制尊重 `prefers-reduced-motion`、后台克制不上动效库、漂移门禁的存在。本文其余内容作为历史记录保留，不再作为现行约束。
- 日期：2026-10-30
- 来源：issue #1（JellyBin 双前端视觉体系重构 spec）与 issue #14（文档落档）；决策来自 2026-10-30 的 grilling 会话；落地分票 #2–#13

## 背景与问题

两端前端都是"模板感的 SaaS 界面"，而不是一个有立场的个人博客：

- **配色是通用货**：主色是发灰的青绿 `#0f766e`（读者站 20 处 hex、`rgba(15,118,110,α)` 42 行），中性色是 Tailwind 石板灰，页面底色是奶油到冰蓝的三段渐变。颜色同时存在于三处：`tailwind.css` 的 `:root` token、组件里的字面 `rgba()`、Naive `themeOverrides`（后台另有约 30 处 `rgba()`）。
- **形状语言与目标相反**：圆角 18/12/26/14/16 与灰线、阴影一起把页面做成卡片堆；目标气质是"图纸工程感"。
- **暗色是半成品**：站内有 cookie `blogx-theme` 驱动的开关与 Naive 主题切换，但两个前端都没有 Tailwind 配置，`darkMode` 落到默认 `media`，那 8 处 `dark:` 工具类只跟操作系统、不跟站内开关；AI 卡片与面板被 `#ffffff !important` 钉死，切暗色像一块补丁；原生控件 `color-scheme` 固定为 light。
- **中文从未真正加载**：`@fontsource/noto-sans-sc` 在依赖里但从未 `@font-face` 加载，中文实际掉到系统字体（PingFang / MS YaHei）。
- **没有动效体系**：全仓没有 motion 库、没有 `<Transition>`、`prefers-reduced-motion` 0 处。

## 决策

1. **五色锁死**：只用五个色相——克莱因蓝 `#002FA7`、奶油白 `#FDFBF6`、包豪斯黄 `#F5C518`、珊瑚橙 `#FF6B4A`、暖灰 `#F2EEE6`；禁止新增第六个色相。同色相只派生明度/透明度变体；黄永不做字色（只做记号笔高亮底与填充）；珊瑚橙作字色时用派生暗橙以满足 WCAG AA。
2. **两层 token + 单一颜色来源**：原始层（五个色相，带品牌前缀）→ 语义层（底色、次级底色、纸面、墨色、次级墨色、结构线三档、高亮底、危险、危险文字、焦点环、阴影）；组件只消费语义层。暗色是同一组语义 token 的第二份取值，由站点根类（`.dark` / `.theme-dark`）承载。两端各一份 Tailwind 配置承载色板与 `darkMode: 'class'`，Naive `themeOverrides` 从 token 取值，不再各写一份。
3. **圆角归零 + 固定形状语义**：默认圆角 0（仅头像、胶囊标签、捏捏本体用全圆角）；三角 = 包豪斯黄（装饰与编号标记），方 = 珊瑚橙（状态/危险），圆 = 克莱因蓝铺色块（页脚、统计数字底、章节锚点）。结构线一律 1px 克莱因蓝、三档透明度表达层级，不用灰线；40px 暖灰网格底纹只在内容区与侧栏背景。
4. **字体与排版**：英文沿用已自托管的 Sora（保留既有度量匹配 fallback 写法），中文补 Noto Sans SC 的 `@font-face`（依赖已在，配度量匹配 fallback 与 `font-display: swap`）；正文行宽约 68ch、中文正文行高 1.75、标题 700 字重 + 轻微负字距。
5. **动效预算 B（统一三档 + 单一缓动）**：只读者站引入 `motion-v`（2.x，Nuxt 模块；后台只用 CSS 过渡 + Naive 内建过渡）。时长三档 120 / 200 / 320ms，单一缓动 `cubic-bezier(.2,.8,.2,1)`，列表 stagger 40ms；只动 `transform` 与 `opacity`，不引发布局抖动。页面切换只做淡入 + 极轻微位移，不做转场动画。`AnimatePresence` 退场与 `useScroll` / `useInView` 等客户端钩子必须放进客户端挂载守卫，生产构建保留 `vite.ssr.noExternal` 兜底。
6. **全局强制尊重 `prefers-reduced-motion`**：动效退化为无动画或一次性淡入，捏捏退化为静态贴片。
7. **漂移门禁**：扫描两端 `app/**` 的组件与样式，除 token 文件、品牌标志矢量与 OG 生成物外禁止裸十六进制 / `rgba()` 颜色字面量，违例失败并打印文件与行号。既有硬编码按"改造中逐文件收敛、最终必须为 0"接入，不在第一天就要求全绿。
8. **后台同源但克制**：同一套 token 与几何语言、圆角 0、补齐 `app.head`；动效只到 hover / focus / 进出场，不接 motion 库、不做暗色（后台暗色本次不做）。

## 理由与已否决方案

颜色、形状、动效是站点的"编辑立场"，不是皮肤。五色锁死 + 语义层让"品牌色只有一个来源"成为可执行约束（门禁可拦），而不是靠人记住三处同步。动效之所以按"档位 B"（微交互 + 滚动入场 + 页面切换，≤320ms）而不是更丰富或更少，是因为长文阅读优先：动效只负责确认交互与节奏，不能抢注意力，也不能拖慢阅读；同时它是无障碍成本最低的档位（可整体退化为静态）。

已否决的方案：

- **砍掉暗色、只留亮色**：站内已有暗色开关（cookie + Naive 主题），砍掉等于把一个带 bug 的半成品永久化；而暗色恰好是这套品牌最强形态（克莱因蓝铺底 + 奶油白字 + 黄/橙仅作强调）。代价是接受"同一组语义 token 的第二次映射"。
- **全系统统一字体栈（一套字体吃中英）**：会让英文丢掉已自托管且已做度量匹配的 Sora，中文仍掉回系统字体（Noto Sans SC 未加载是既有事实）；中英两套字体栈各配度量匹配 fallback 才是可行的中英混排。
- **叙事性编排（滚动叙事、大幅转场、视差）**：与"≤320ms、只 transform/opacity、强制 reduced-motion"直接冲突；长文阅读会被拖慢，移动端掉帧，且叙事感与"图纸工程感"的克制气质相反。
- **只换皮、不换形状（保留旧圆角与渐变，只把配色换掉）**：模板感来自形状、构图与动效的组合，只换色会得到"染成克莱因蓝的同一个模板"，仍然不是用户要的博客。

## 代价 / 不做什么

- **直角化是最大的一处审美赌注**：圆角归零 + 1px 线在大屏上容易做成"工程稿"而不是博客。缓解：奶油白大面积呼吸、长文排版优先、重点页逐页目视调；必要时把圆角作为可回调的单一 token，但不得散落回组件。
- **Naive UI 深改波及所有组件**：表格、弹窗、抽屉、日期选择都读全局圆角与主色，需逐页目视回归；后台尤其明显。
- **颜色迁移量大**：读者站 42 行 `rgba(15,118,110,α)` 青绿族 + 27 行边框族 + 20 行阴影族，后台约 30 处 `rgba()`；必须靠 token 替换，不能逐处手改。
- **`motion-v` 与 SSR 有接入成本**：客户端挂载守卫、可能的生产构建 `ssr.noExternal` 兜底；若成本失控，动效可退回纯 CSS 过渡（本 ADR 的"档位 B"语义不变）。
- **门禁新红可能来自旧代码**：漂移测试首次运行会把既有硬编码全部点亮，必须逐文件收敛，短期不能要求全绿（否则只能关掉门禁）。
- **不做什么**：后台暗色、后台捏捏、e2e / Playwright / 视觉截图比对、i18n 多语言、字体子集化的极致优化、3D logo 重绘与橙色 logo 变体。
- **无后端只能验交互**：本地起两个前端、后端不起，接口失败走空态/降级态；真实数据下的最终目视调留待后端可用时做。

## 当前生效约束

1. 只用五个色相，禁止新增第六个；同色相只派生明度/透明度。
2. 黄永不做字色；珊瑚橙作字色时必须用满足 WCAG AA 的派生暗橙。
3. 组件只消费语义层 token；暗色是同一组语义 token 的第二份取值，由根类承载，组件不写额外颜色决策。
4. 颜色只有一个来源：语义 token 层；Naive `themeOverrides` 从它取值。
5. 圆角默认 0，只有头像、胶囊标签、捏捏本体例外。
6. 结构线一律 1px 克莱因蓝（三档透明度），不得用灰线。
7. 动效仅三档 120 / 200 / 320ms + 单一 `cubic-bezier(.2,.8,.2,1)` + stagger 40ms，只动 `transform` / `opacity`。
8. 所有动效强制尊重 `prefers-reduced-motion`（无动画或一次性淡入）。
9. `motion-v` 只装在读者站；后台只用 CSS 过渡与 Naive 内建过渡。
10. 组件与样式禁止裸颜色字面量（token 文件、品牌标志矢量、OG 生成物除外），由漂移门禁拦。
