# 08 · 重构任务清单（执行版）

> 这是"照着做"的清单：**任务、依赖、验收命令**。为什么这么做见 [04](./04-迁移路线图.md)、[06](./06-质量保障与治理.md)、[07](./07-日志模块治理.md)。
> 目标：每一步都能编译、能上线、能回滚；不接受"看起来做了"。

---

## 0. 执行纪律

1. **一个任务 = 一个可独立 review 的 commit**（或小 PR）。任务 ID 写进 commit message，例如 `S1.2: ci run go test -race`。
2. **每个任务必须有"验收命令"**，跑不过不算完成。
3. **先 `--warn` 后 `--error`，先新增后删除**：新结构跑通再删旧代码。
4. **任何阶段结束都必须能编译、能上线**；主干始终可发布。
5. **不做大爆炸重写**：article 先试点，验证模式后再批量。

> **M7 是 M6 之后新增的里程碑**（2026-10-26 拍板）。它修的是 ADR-003 遗留的问题：
> 契约要靠 `fix-openapi-id-types.mjs` 后处理才正确。详见
> `adr/ADR-007-ID类型统一为string底层.md` 与 `10-M7决策清单.md`。

**为什么 L 与 T 不再跨里程碑切分（2026-10-24 拍板）**：

- **日志是端到端管道，不能半截。** 只做 L.1/L.2（事件 + sink）而把 L.3–L.5 推到 M6，
  意味着中间整个阶段"平台层日志已建好、生产路径却还在同步落盘"——新旧两套并存，
  既拿不到收益，又要维护两份。且 L.3（替换写入口）单独做会丢审计日志，
  **必须先有 L.4 的 WAL 兜底**。所以 L.1–L.5 必须作为一个整体在 M3 交付。
  M6 只留 L.6–L.9（删旧 Hook、去雪花、TTL 与压缩、日志规则）；审计字段瘦身 L.10 已提前执行，
  不占 M6 工期。
- **测试基建同理。** T.3（testkit）与 T.4（有状态 fake）是同一套东西的两半：
  只有 testkit 没有 fake，新模块依然只能连着真库测。所以 T.3/T.4/T.8 的**基建部分**归 M3。
  但 T.4 里的 article/comment/user fake **依赖 domain 实体**，那是依赖顺序而非成本问题——
  这部分随各模块自己的 domain 一起交付（article 在 M4，其余在 M5），硬提前只会造出假的实体。

**并行轨道**：`L`（日志）与 `T`（测试）贯穿 M1–M5，但 **T1（CI 建闸）必须与 M1 同时完成**——没有验证手段，后面都是盲改。

## 7.5 M7 契约根治（方案 E：ID 类型即真相）

**目标**：让 Go 里的 ID 类型和它在 JSON 里的样子是同一个东西。类型改 `string` 后 `swag` 不可能印
`integer`，后处理脚本与 `.swaggo` 一并删除。数据库侧 `Value`/`Scan` 仍走 int64，**零 DDL**。

**为什么不用更省事的方案 A（`.swaggo` 覆盖）**：A 只覆盖 `ctype.ID` 那 61 处，剩下 75 处要另改，
且"类型是数字、传输是字符串"这层隐式转换还在——以后谁新写个 `uint64` ID 字段，契约会再错一次。
E 工作量约是 A 的两倍（240 处 vs 119 处），买的是**根因消失**。

| 阶段 | 任务 | 处数 | 状态 |
| --- | --- | --- | --- |
| P0 | 清 M6 遗留 3 项（useStudio* 测试 / InboxChatPanel 协议 / S2.8 字段注解） | — | ✅ 49 + 11 用例；门槛升至 60/50/66/60 |
| E1 | 10 个 ID 类型改 string 底层 + `ctype.ID` 方法集（`Uint64`/`IsZero`/`ParseID`；`UnmarshalJSON` 须同时接受数字与字符串） | 40 | ✅ |
| E2 | 业务适配：`uint64(x)`→`x.Uint64()`、`x==0`→`IsZero()`、`return 0`→`""`（编译器牵引，二轮会再露 ~10 处） | 148 | ✅ 实为 3 轮收敛 |
| E3 | 裸 `uint64` ID 字段收编（`HomeStyleID`/`account.ID`/`row.UserID`/JWT claims） | **175**（原估 22） | ✅ 收编 149，26 按理由豁免 |
| E4 | 测试文件适配 + **6 处大小比较语义审查** + golden 基线重生成 | ≥21（实 ≈90） | ✅ 另修掉 `BuildSessionID` 串号隐患 |
| E5 | 删 `.swaggo` 与 `fix-openapi-id-types.mjs`，验证契约一次生成就对 | — | ✅ 契约里 integer 型 ID = 0 |
