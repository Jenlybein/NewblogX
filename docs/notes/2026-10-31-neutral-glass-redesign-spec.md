# JellyBin：中性石墨阶 + 液态玻璃 + 编辑部式首屏（视觉立场反转）

> 状态：spec，已发布为 [#17](https://github.com/Jenlybein/NewblogX/issues/17) 并打 `ready-for-agent`（本文与 issue 正文同源，改动请两处同步）。
> 来源：2026-10-31 的 grilling 会话（26 + 12 条决策）+ 两路只读勘查（两端主题系统全量审计、Apple 液态玻璃解构）。
> 决策记录：ADR-0012（取代 ADR-0010 的视觉立场）· ADR-0013（首屏例外区）。
> 适用边界：只碰两端呈现层、漂移门禁与设计测试；后端、OpenAPI 契约、路由、部署标识（`BLOGX_*`、compose 服务名、cookie 键）都不动。

## Problem Statement

站点能用，但用户认为它不好看：主色调伤眼，且"高级感"缺席。具体表现为十处可验证的病灶：

- **蓝色在三个量级上都过载**：暗色模式整页铺 `#001b63`、纸面 `#001f70`（大面积高饱和深蓝）；页脚与统计块是 `#002FA7` 满铺；而全站的 1px 分隔线、悬停底、阴影都是 `rgba(0, 47, 167, α)`，连正文墨色也是蓝黑 ——"每个黑色其实都是深蓝"。
- **圆角归零从未执行到底**：写作区设置页有 9 处 `rounded-[18px]`、历史页 18px、收藏页 `rounded-2xl`、聊天面 `rounded-lg`、收藏夹弹窗 `rounded-[22px]`；品牌矢量自己写着 `rx=4/3/1`。门禁只查少数结构类，CI 一直是绿的。
- **形状语义把颜色绑死在几何记号上**（三角=黄、方=橙、圆=蓝），蓝色一退役，这套语义整体失去锚点。
- **顶栏刻意非吸顶**（代码注释写着"滚动时永远不遮挡正文"），而目标美学的骨架正是吸顶半透明导航。
- **16 个语义 token 把 `rgba(0, 47, 167, α)` 写死**，不跟随主色变量 —— 只改主色字面量，全站结构线、阴影、hover 底仍是旧蓝。
- **漂移门禁有盲区**：573 行 CSS 藏在 TS 字符串里不被扫描；hex 正则被 `_` 转义绕过（写作页因此留着一处写死的亮色渐变）；阅读站缺后台那样的"禁用默认调色板类名"测试。
- **三个 token 根本没定义却在使用**（`--font-title`、阅读站 `--font-mono`、`--color-on-strong-soft`/`-line`），静默降级成继承值或透明。
- **md 写作页没有暗色开关且暗色下发白**：该布局根本不渲染页头（开关唯一落点），且写死了亮色渐变与 `text-slate-900`。
- **暗色 Logo 是一块白瓷砖**：暗色切到一个**无 alpha 通道**的白底 PNG，`<img>` 又没有裁剪，于是白色方块完整压在深色顶栏上。
- **首屏是一张卡片**：带 1px 边框与纸面底色的容器，里面是"品牌小字 + 一句主张 + 三格统计 + 两个入口"；而用户想要的是一张满幅的编辑部式封面。

## Solution

一次呈现层重构，把"克莱因蓝主色 + 圆角归零 + 图纸工程感"换成"中性石墨阶 + 圆角阶梯 + 只落在导航/控制层的液态玻璃"，并给首屏开一个**满幅编辑部式封面**的例外区。十项对应解法：

1. **中性石墨阶接管墨色与结构线**：克莱因蓝退役其"主色 / 铺底 / 墨色 / 结构线"角色；墨色与发丝线改为暖石墨（亮色）与中性暗阶（暗色）。色相仍是五个锁定色相：奶油白、暖灰、珊瑚橙、包豪斯黄（仅记号笔高亮底）、功能蓝（仅链接与焦点环）。
2. **圆角阶梯取代圆角归零**：`8 / 14 / 20 / 28 / pill` 五档，控件、卡片、浮层、胶囊各归其位，5 处逃逸一并归位。
3. **液态玻璃只给导航/控制层**：两档玻璃（导航薄玻璃、浮层厚玻璃），带 1px 折射边缘、噪点层与指针镜面高光；正文、卡片、列表一律不透明实体面。
4. **顶栏改吸顶玻璃导航**：高度压到 56–64px，滚动后转玻璃，**方向感知**（下滚隐藏、上滚出现），全站补 `scroll-padding-top`。
5. **动效放宽到档位 C**：全站区块级滚动进场 + 导航转玻璃 + 视差 ≤10px；正文段落不进场，强制 `prefers-reduced-motion`。
6. **字体分工**：Sora 负责字标与大标题，Inter 负责正文与 UI，中文继续 Noto Sans SC；全站无衬线；补上两个缺失的 token。
7. **首屏编辑部式封面**：满幅色带（黄/功能蓝/珊瑚）、超大 `h1`（`JELLYBIN` + `[果冻盒]`）、网格刻度、方括号/箭头记号、胶囊小签；底图用运营上传的首张轮播；轮播控件并入首屏；不做人像抠图。
8. **两端同步 + 后台启用暗色**：每页都可见主题开关（含 md 写作页与后台登录/初始化页）；后台密集信息面不上玻璃，以对比度为先。
9. **Logo 白边修复 + 品牌资产例外**：删掉"暗色专用 Logo"变体，两套主题统一用透底资产；品牌图形保留自身颜色（同 App 图标惯例）。
10. **把新立场变成可执行约束**：扩展漂移门禁（扫 `.ts` 里的 CSS、修 `_` 转义、补阅读站 legacy-colors 测试）、新增两端 token 逐字节同步门禁、扩展设计测试。

## User Stories

**读者 · 首次访问**

1. 作为第一次打开站点的读者，我想在第一屏就感到这是一个人精心做过的博客而不是套模板，这样我才愿意往下读。
2. 作为读者，我想首屏用运营上传的图做满幅封面，这样站点看起来是"活的"而不是一张海报。
3. 作为读者，我想首屏的大标题一眼说出站名，这样我 3 秒内就知道自己在哪。
4. 作为小屏手机读者，我想首屏不要因为满幅而被挤压、不要出现横向滚动条，这样滑动是顺的。
5. 作为弱网读者，我想封面图加载失败时首屏仍然成立（色带 + 大标题还在），这样我不会看到一片空白。

**读者 · 阅读与导航**

6. 作为读者，我想页头在我往下滚时变成半透明玻璃、往上滚时重新出现，这样我随时能回去导航但不被一条横带永久压着。
7. 作为读者，我想从目录或锚点跳转时标题不被吸顶页头挡住，这样我点到的位置就是我想看的。
8. 作为读者，我想正文背后没有任何模糊层，这样长文阅读时文字永远清晰、对比度稳定。
9. 作为读者，我想滚动时区块有轻微的淡入与极小的位移，这样页面在滚动中"呼吸"，但正文段落不跟着动，读起来不晕。
10. 作为读者，我想整站的链接颜色与焦点环一致且可见，这样我能快速识别"哪里可以点"。

**读者 · 明暗与无障碍**

11. 作为夜间阅读的读者，我想暗色模式是中性近黑而不是整页深蓝，这样长时间阅读不刺眼。
12. 作为读者，我想暗色下玻璃不是一块灰板而是有边缘亮的材料，这样它看起来像玻璃而不是脏污。
13. 作为对动态敏感的用户，我想在系统开启"减少动态"时没有任何进场、视差与指针高光，这样我不会头晕。
14. 作为对透明度敏感的用户，我想在系统开启"减少透明度"时所有玻璃退化为不透明面，这样文字始终可读。
15. 作为键盘用户，我想每个可聚焦控件都有清晰的焦点环，这样我能看见自己在哪。
16. 作为弱视用户，我想正文对比度不低于 4.5:1、非文字图形不低于 3:1，这样我不用放大也能读。

**读者 · 创作区**

17. 作为登录后的作者，我想在 md 写作页也能切换明暗，这样夜间写作时页面不刺眼。
18. 作为作者，我想写作页在暗色下不是写死的亮色渐变，这样切换主题立刻生效。

**管理员**

19. 作为管理员，我想后台也支持暗色且每页都有开关，这样我在长时间配置时不刺眼。
20. 作为管理员，我想后台的表格、表单、弹窗保持高对比度不上玻璃，这样密集信息仍然一眼看清。
21. 作为管理员，我想后台登录页与初始化页也能切换主题，这样首屏配置就在我习惯的模式下。

**维护者（开发者）**

22. 作为维护者，我想颜色只有一个来源（两端 token 逐字节一致），这样我改一处不会出现"改了没生效"。
23. 作为维护者，我想改主色时所有带透明度的线、阴影、hover 底自动跟着变，这样我不需要逐处找写死的 alpha。
24. 作为维护者，我想漂移门禁能扫到藏在 TS 字符串里的 CSS、也能抓到 `_` 转义的十六进制，这样门禁不再自称通过而实际漏检。
25. 作为维护者，我想圆角与玻璃只从 token 取值，这样任何地方都不能私自写 `rounded-[18px]`。
26. 作为维护者，我想玻璃出现在哪些组件由测试锁死，这样别人不会把玻璃铺到正文上。
27. 作为维护者，我想"哪些改动会让门禁变红"有可执行的 canary 测试，这样我能证明门禁真的会红而不是永远绿。
28. 作为维护者，我想首屏的例外区（色带/刻度/记号）被约束在单个组件里，这样它不会扩散到列表页。
29. 作为维护者，我想删掉不用的旧字段与函数（主旨句、三格事实），这样仓库里不留无消费点的死代码。
30. 作为维护者，我想 12 个外部 markdown 主题不影响阅读站默认主题，这样作者预览与读者呈现不会互染。

**品牌所有者（用户本人）**

31. 作为站点所有者，我想 logo 在任何主题下都不出现白色方块，这样页头不会像贴了张纸。
32. 作为站点所有者，我想品牌图形（电光蓝果冻）保留自己的颜色，这样站点辨识度不丢。
33. 作为站点所有者，我想"一个会呼吸的个人博客"不再重复出现在页头、首屏与页脚的三个位置，这样品牌表达更干净。
34. 作为站点所有者，我想首页不再挂三个"0 / 0 / 9 篇"的统计格，这样首屏是主张而不是仪表盘。

## Implementation Decisions

**决策出处与替代关系**

- ADR-0012 取代 ADR-0010 的色相集合与主色、圆角政策、结构线规则、形状语义、动效档位与"顶栏非吸顶"；ADR-0010 中继续有效的是：两层 token + 单一颜色来源、暗色为同一组语义 token 的第二份取值、强制 `prefers-reduced-motion`、后台克制不上动效库、漂移门禁的存在。
- ADR-0013 是 ADR-0012 的**首屏唯一例外**：满幅色带（黄/功能蓝/珊瑚）仅在首页首屏允许作装饰，其他任何地方仍受 0012 约束。

**语义色 token 表（两端各一份，目标状态逐字节同源）**

- 原始层五个锁定色相：奶油白 `#FDFBF6`、暖灰 `#F2EEE6`（含提亮派生 `#F5F3EE`）、珊瑚橙 `#FF6B4A`（填充）/ 派生暗橙 `#C2401F`（AA 文字）、包豪斯黄 `#F5C518`（仅高亮底）、功能蓝 `#0066CC`（亮）/ `#2997FF`（暗）（仅链接与焦点环）。禁止新增第六个色相。
- 中性石墨阶是暖灰的去彩派生层级，不是新色相：亮色墨 `#1C1B19` / 次级 `#625C52` / 极淡 `#8A8378`；发丝线取墨色的 `0.10 / 0.16 / 0.32`。
- 层次反转（亮色）：底 `#F5F3EE` / 次底 `#F2EEE6` / 面 `#FDFBF6` / 抬升 `#FFFFFF`。
- 暗色采用苹果实测中性暗阶：底 `#161617` / 次底 `#101011` / 面 `#1D1D1F` / 抬升 `#2C2C2E`；墨 `#F5F5F7` / 次级 `#A1A1A6` / 极淡 `#86868B`；线为 `#F5F5F7` 的 `0.08 / 0.14 / 0.28`。**刻意不取暖黑**：暖黑压上白玻璃会发浊；明暗色温断层由玻璃边缘带用暖白接住。
- 所有带透明度的取值必须由 `rgb(var(--*-rgb) / α)` 三元组派生，**禁止写死的 `rgba(r,g,b,α)` 常量**；这条是替换 16 处硬编码 alpha 的机制。
- 已退役：克莱因蓝 `#002FA7` 与它的八档明度派生、无消费者的过渡层旧变量（含 v1 的青绿 `--accent`）、40px 暖灰网格底纹。

**液态玻璃层（只允许出现在导航/控制层）**

- 两档：薄玻璃（导航、胶囊、徽标）`blur 20px` + `saturate 180%` + 亮 `rgb(255 255 255 / .72)` / 暗 `rgb(22 22 23 / .72)`；厚玻璃（弹窗、抽屉、捏捏面板）`blur 28px` + `saturate 160%` + `alpha .80/.82`。
- 边缘靠 1px 折射带（伪元素 + `padding: 1px` + `mask-composite: exclude`，不用 `border`，因为 `border` 会被裁掉高光）；噪点层用内联 `feTurbulence` data-URI，亮 `.055` / 暗 `.045`；指针镜面高光由 `--mx`/`--my` 变量驱动径向渐变，不改布局。
- `backdrop-filter` 会让元素成为 **backdrop root**，嵌套玻璃无法糊到页面、只会读成平灰 —— 所以"同屏可见玻璃层 ≤3"是硬约束，嵌套卡片一律不透明。
- 降级链：`@supports not (backdrop-filter)` → 不透明面；`prefers-reduced-transparency: reduce` → 不透明面；`prefers-reduced-motion: reduce` → 关指针高光与进场；移动端（<768px）`blur` 降到 12px 并关闭指针高光。

**圆角阶梯**

- `8 / 14 / 20 / 28 / pill` 五档 token；映射：输入与控件 8–14、卡片 20、弹窗与大浮层 28、胶囊与徽标 pill。
- 嵌套层子圆角 = 父圆角 − 内边距（同轴曲率，避免边缘高光错位）。
- 现存 5 处圆角逃逸归 token；Naive 主题覆盖层的 `borderRadius`/`borderRadiusSmall` 也从这里取值。

**排版**

- `--font-display` = Sora（字标、品牌记号、大标题 hero/页面标题）；`--font-latin` = Inter（正文与 UI）；中文 = Noto Sans SC；**全站不使用衬线体**。
- 补上两个缺失 token：`--font-title`（取 `--font-display`）与阅读站 `--font-mono`（修掉 prose 代码块掉回 sans）。
- 大标题字距收到 `-0.03em`。

**动效档位 C**

- 保留三档时长 `120/200/320ms`、单一缓动 `cubic-bezier(.2,.8,.2,1)`、stagger `40ms`。
- 新增 `--motion-reveal-offset`（12px，滚动进场位移上限）与 `--parallax-max`（10px）。
- 全站**区块级**滚动进场（hero、列表条目、卡片、侧栏、区块容器），单区块只进一次；**正文 markdown 段落不进场**。
- 实现用已有的 `motion-v` 的 `useInView`/`useScroll`，沿用既有客户端挂载守卫；`prefers-reduced-motion` 下全部归零。

**吸顶玻璃导航**

- 页头从非吸顶改为 `sticky`，高度 56–64px；滚动超阈值后加模糊与底部 1px 边缘高光。
- **滚动方向感知**：下滚隐藏、上滚出现（保留"不永久遮挡正文"的原始动机）。
- 全站补 `scroll-padding-top`，锚点不被页头遮挡。
- 页头仍是主题开关的唯一落点。

**首屏编辑部式封面（ADR-0013）**

- 分层（自下而上）：底图（运营上传的首张轮播 `cover`，无图时版式仍成立）→ 罩层（保证文字 4.5:1）→ 2–3 条横向色带 → 网格线 + 下沿刻度 → 超大 `h1` → 箭头/方括号/胶囊小签 → 玻璃胶囊轮播控件。
- **首屏 `h1` 是超大标题**（`JELLYBIN` + `[果冻盒]`），不再是 11px 小字；页面因此有且仅有一个 `h1`。
- 满幅实现：`100vw` + 负边距 bleed，外层 `overflow-x: clip` 防横向滚动条；高度 `clamp(380px, 62vh, 620px)`；两栏 grid（左文字 / 右刻度）。
- 窄屏（<768px）：色带 ≤1 条，隐藏刻度与方括号/箭头，标题 `clamp(2rem, 9vw, 3rem)`，内容纵向堆叠。
- 轮播**并入首屏**：≥2 张才显示箭头与圆点，走薄玻璃；首屏下方不再出现独立轮播卡；空态沿用既有空态组件。
- **删除项**：`BRAND.tagline`「一个会呼吸的个人博客」从页头（logo 旁小字）、首屏大标题、页脚三处全部移除，并从品牌模块删掉该字段；首屏三格统计（置顶/本页最新/每页）连同其纯函数与单测一并删除；首屏卡片的边框与纸面底色删除。

**两端同源与后台**

- 两端各维护一份语义色 token 表，新增**逐字节一致**的同步门禁（不一致即 CI 红）。
- 后台启用暗色；**每个页面都必须有可见主题开关**（阅读站 `/studio/write` 整条布局不渲染页头，要补开关或补页头；后台登录/初始化布局也要有）。
- 后台密集信息面（表格、表单、弹窗内容区）不上玻璃，以对比度为先。
- 两端 Naive 主题覆盖层随 token 重写：阅读站的 primary 改为墨色（CTA 是墨水实心胶囊）、info 留给功能蓝；后台那层 322 行的中性调色板去掉硬编码 alpha，改走 `--*-rgb` 派生，并接入圆角与暗色映射。

**品牌资产**

- 电光蓝果冻渲染图与扁平矢量果冻作为**品牌资产例外**保留自身颜色（同 App 图标），门禁豁免不变。
- 暗色白边修复：删掉按主题切换 Logo 的整套逻辑、`logoWhite` 资产键与那张**无 alpha 通道的白底 PNG**，两套主题统一用透底资产；品牌资产不再有"暗色专用变体"。

- 漂移门禁：扫描目标扩到 `.ts` 里的 CSS 字符串；修掉 hex 正则的 `_` 转义漏洞；补阅读站"禁用 Tailwind 默认调色板类名"测试。

## Testing Decisions

**什么算好测试**

- 只测外部行为与契约，不断言实现细节：既有的页头组件测试已经确立了这条约定（断言结构、无障碍状态与交互接线，**不断言具体 CSS 类名**），新测试沿用。
- 对"设计系统"而言，token 表本身就是外部契约：断言取值、断言派生机制成立、断言不允许的用法为零，比断言某个组件的盒子更稳。
- 门禁类测试必须包含**人造违规**（canary）：证明门禁真的会红，而不是永远绿。这是本仓既有的门禁自检文化。
- 动效测试断言"减少动态 = 归零"而不是"变慢"；玻璃测试断言"出现位置"与"降级分支"，不去比像素。

**要测的模块**

- **静态设计契约（最高 seam，扩展现有文件而非新建目录）**：token 表取值与明暗映射；发丝线与阴影确实由 `rgb(var(--*-rgb)/α)` 派生（禁止写死 alpha）；圆角阶梯存在且全站无反例字面量；玻璃 token 两档存在且只被允许的组件消费；字体栈与缺失 token 已补齐；动效档位 C 的四个 token 存在且 `motion.ts` 一致；首屏封面结构（唯一 `h1`、色带/刻度/记号类名只出现在首屏组件、轮播已并入）；删除项为零（主旨句、`homeHeroFacts`、`logoWhite`、暗色专用 PNG）。
- **门禁**：漂移门禁的新规则（`.ts` CSS 字符串、`_` 转义）用人造违规证明会红，用真实仓库证明为绿；token 逐字节同步门禁用"故意改一端"的人造不一致证明会红。
- **运行时行为（组件挂载 seam）**：页头主题开关在明暗两态都可见且可切换；每个布局（含 md 写作布局与后台 auth 布局）都渲染开关；吸顶页头的方向感知与阈值（下滚隐藏/上滚出现）；首屏封面在无 `banners` 时仍渲染标题与色带；轮播控件在 1 张时不渲染、≥2 张时渲染。
- **composable seam**：滚动方向/阈值 composable（方向、阈值、reduced-motion 下不启用）与指针镜面 composable（`--mx/--my` 写入、移动端与 reduced-motion 下不写入）。
- **纯函数 seam**：品牌模块删除 `tagline` 后的导出面；`utils/motion` 的新常量。

**先例（对应到现有测试）**

- 静态设计测试：`test/design/*`（tokens、dark-tokens、dark-surfaces、rounding、fonts、motion-foundation、reduced-motion、home-entrance、gate-wiring）与后台 `test/unit/*`（tokens、fonts、legacy-colors、design-tokens）。
- 门禁 canary：`test/gates/design-tokens.test.ts`（临时项目 + 人造违规 + 真实仓库为绿的三段式）。

## Further Notes

- **落地顺序（4 批 + 1 个可独立先发的修补）**：① Logo 白边 bugfix（独立，不阻塞）→ ② token 层重建（含同步门禁与门禁扩展）→ ③ 全局层（形状语义解散、颜色语义切换）与首屏编辑部式封面 → ④ 玻璃层、吸顶顶栏与动效 → ⑤ 逐页校准、门禁归零与文档收口。
- **最大风险来自用户明确选择的"全站滚动进场"**：长文页多处同时进场，低端机掉帧、观感眩晕。护栏已固定：位移 ≤12px、单区块只进一次、正文段落不进场、stagger 40ms 上限、强制 reduced-motion。
- **次大风险是玻璃的性能与可读性**：同屏 ≤3、移动端降模糊、两类降级都要落地；这不是一次性改动而是长期维护成本。
- **两份 token 表是永久的同步义务**：加逐字节门禁把它从"纪律"变成"门禁"，但仍是两份文件；抽共享包已评估并否决（两端各有 workspace 与独立 lockfile）。
- **例外区必须被锁住**：首屏的色带/刻度/记号是刻意破例，需要一条设计测试断言这些类名只出现在首屏封面组件内，否则半年后会被复制到列表页。
- **完成定义**：本地一键门禁全绿（含新同步门禁与设计测试）、两端明暗逐页目视签核、对比度达标、每页有开关、四类降级生效；交付后把 ADR-0012 / ADR-0013 的状态改为 `已交付`（不改结论）。
- **文档关联**：ADR-0010（已取代）· ADR-0012（全站规则）· ADR-0013（首屏例外）· `GLOSSARY.md`（语义色 token / 中性石墨阶 / 功能蓝 / 液态玻璃层 / 圆角阶梯 / 品牌资产例外 / 动效档位 / 首屏封面）· Apple 液态玻璃解构 · 中性玻璃改造方案。
