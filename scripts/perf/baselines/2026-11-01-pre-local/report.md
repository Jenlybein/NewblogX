## 备注

- 改前（本地生产构建）：main 5530bb8 的构建跑在 127.0.0.1:3001（API 上游 gentlybeing.cn）；P0（#80）未修，站内跳转崩溃，切页内容可见不可测；返回场景站内点击进不去文章，entryFlow=document（进文章退化为文档级 goto）。此份与 2026-11-01-post-local 使用同一版脚本与同一口径。
- 切页「首页 → 文章」· 冷：3/3 次点击后内容在 12000 ms 内从未出现，结论记作不可测（从不出现）；首次异常：n.off is not a function。
- 切页「首页 → 文章」· 热：3/3 次点击后内容在 12000 ms 内从未出现，结论记作不可测（从不出现）；首次异常：n.off is not a function。
- 返回「首页 → 文章 → 返回首页」· 冷：站内点击没能进入文章页（点击导航不可用，P0 #80 时代的形态），进文章退化为文档级 goto（entryFlow=document）；返回本身是SPA 返回。该行只作改前对照，不代表客户端缓存的最终形态。
- 返回「首页 → 文章 → 返回首页」· 热：站内点击没能进入文章页（点击导航不可用，P0 #80 时代的形态），进文章退化为文档级 goto（entryFlow=document）；返回本身是SPA 返回。该行只作改前对照，不代表客户端缓存的最终形态。
- 字体字节是资源计时里的体积（encodedBodySize）：热模式即便命中 HTTP 缓存，该体积仍会被报告，它不代表热启动的新增下载量；字体预算判定以冷模式为准（新增下载量看 transferSize，本报告未单列）。
