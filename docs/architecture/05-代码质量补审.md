## 3. 功能性缺陷

### 3.1 依赖注入导致的测试不可行

现状 30 个 `Deps` 含 `*gorm.DB`，导致：

- 任何 service/handler 测试都要构造完整 `Deps`（17 个字段）
- 无法注入"数据库故障"这类场景
- 因此 **`repository/` 449 行核心 SQL 层 0 测试**
- 全项目只有 3 处 `t.Parallel`（且全在 `cron_service/log_cleanup_test.go`）

**这不是"懒得写测试"，是结构不允许。**

### 3.2 架构守卫造成的虚假安全感

见 `01 §4`。补充一个后果：

`test/architecture/no_global_refs_test.go:40` 检查 `"myblogx/global"` 引用——但该包**不存在**。这个测试永远通过，于是"我们有架构测试"成了一个事实陈述，而它什么都不测。

### 3.3 复制粘贴造成的审计缺口

```go
// api/article_api/category/category_create_update.go  → 有 EmitActionAuditFromGin
// api/article_api/favorite/favorite_*.go              → 复制时没带过来
```

结果：全仓 **21 处审计埋点 / 138 个 api 文件 = 15% 覆盖**。

哪条链路有审计，取决于当初从哪个文件复制的。这是**审计合规风险**，不是代码风格问题。

### 3.4 优雅停机失效

```go
// app/lifecycle.go:32  OnStop  —— 0 个调用点
```

⇒ `stopHooks` 永远为空 ⇒ `WaitForShutdown` 只打一行日志 ⇒ 进程收到 SIGTERM 后**直接退出**，不等在途请求。

配合"无 CI、无生产 compose"，这个问题的暴露路径是：发版时正在写的文章可能丢。

### 3.5 版本不可追溯

```go
// buildinfo/version.go  —— 46 字节
const Version = "1.0.0"
```

无 `-ldflags` 注入 ⇒ 线上实例无法回答"这是哪个 commit"。出问题只能靠猜。

### 3.6 前端 WebSocket 无背压

```ts
// apps/web/server/routes/api/chat/ws.ts:134
state.queue   // 无上限
```

上游停在 `CONNECTING` 时消息无限堆积 → 内存泄漏。且：
- 无 ping/pong 心跳
- `upstream.on("error")` 只 `closePeer`，不 `terminate()`（`:110-113`）→ 半开连接滞留
- 生产环境 nginx 对 `/api/chat/ws` 直接 `proxy_pass`（`nginx.production.conf:60-73`），**Nitro 的 ws 代理实际不生效** ⇒ 开发/生产行为不一致

### 3.7 前端 store 循环依赖

```
auth.ts:7-8      → import chat, message
message.ts:37    → useAuthStore()          ← 反向
auth.ts:116-117  → logout 里调 useMessageStore().clear()
                   与 useChatStore().resetSocketState()
```

登出流程横跨三个 store，任何一个初始化顺序变化都可能出问题。

## 5. 优先级

按"风险 × 修复成本"排序：

| 优先级 | 项 | 理由 |
| --- | --- | --- |
| **1** | 优雅停机（`Lifecycle.OnStop` 未接入） | 发版丢数据的直接原因，修复成本极低 |
| **2** | 审计缺口（15% → 100%） | 合规风险；由复制导致，需系统性检查 |
| **3** | WS 无背压 + 生产被 nginx 旁路 | 内存泄漏 + 环境不一致 |
| **4** | 版本不可追溯 | 排查成本，改一个 ldflags 即可 |
| **5** | `article_sync.go` 1,547 行 | 后续所有 ES 相关改动都要读它 |
| **6** | 重复代码 | 影响长期维护，但不紧急 |

**注意**：这六项里前四项都不在"架构"范畴，而是**运维可靠性**。它们比分层问题更该先修——因为分层重构要几个月，而这些是几小时的事。
