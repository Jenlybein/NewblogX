# ADR-0013：首屏编辑部式封面（满幅色带 + 超大字号，仅首屏例外）

- 状态：已交付
- 日期：2026-10-31
- 来源：2026-10-31 的 grilling 会话（用户以瑞士/编辑部式版式参考图提出"首屏容器替换成类似风格"）；spec 为 [issue #17](https://github.com/Jenlybein/NewblogX/issues/17) 的一部分。上游决策为 [ADR-0012](./0012-neutral-glass-visual-system.md)，改造落点见 [中性玻璃改造方案](../notes/2026-10-31-neutral-glass-redesign-plan.md)

## 背景与问题

ADR-0012 定下的全站气质是"中性石墨阶 + 圆角阶梯 + 只落在导航/控制层的液态玻璃"，首屏原本是一个带 1px 结构线与纸面底色的"卡片"（`pages/index.vue:200-209` 的 `.home-hero`）。用户提供的参考图是**瑞士/编辑部式图形版式**：满幅横向色带、超大黑体、网格与刻度、方括号与箭头记号、黑底白字胶囊小签、抠图人物。

两者是两套气质，不能简单地"整站都换"，也不同意把首屏继续留成一个框。同时暴露了几处必须一起处理的存量问题：

- 首屏是**卡片式容器**（边框 + 底色 + 内边距），与"满幅图形封面"直接冲突，且满幅需要脱离 `page-shell` 的 `max-w-[1360px] px-4`。
- 首屏主张句来自 `BRAND.tagline`「一个会呼吸的个人博客」，它同时出现在**页头 logo 旁**（`AppHeader.vue:123` 的 `.site-header__abstract`）、**首屏 h1**（`index.vue:129`）与**页脚**（`AppFooter.vue:31`）三处 —— 同一句话重复三次。
- 首屏右上角有"置顶 / 本页最新 / 每页"三格事实（`homeHeroFacts()`，`utils/home.ts:164`），在满幅版式里无处安放。
- 现有轮播是首屏**下方**的独立卡片（`BannerCarousel.vue` 的 `.banner-shell` 边框 + 内边距），满幅封面需要的是"首屏即轮播舞台"。
- 参考图的大面积色带（黄 + 蓝 + 深紫）与 ADR-0012 已锁死的色相职能冲突：黄只做记号笔高亮底、功能蓝只做链接与焦点环。

## 决策

1. **首屏是唯一的编辑部式例外区**。全站只有首页首屏可以出现满幅色带、超大黑体、网格刻度与记号系统；列表页、文章页、个人页、创作区与后台一律不得复用。
2. **首屏改为满幅封面**：脱离 `page-shell` 的水平内边距（bleed 技术铺满视口，并处理横向滚动），**没有边框、没有纸面底色**，直接坐在页面底上。
3. **版式元素**：横向色带（2–3 条）、超大黑体标题、细网格线 + 下沿刻度数字、黑底白字胶囊小签、方括号与箭头记号。**不做人像/抠图**（我们没有人物素材，且不引第三方插图）。
4. **色带配色是首屏专属例外**：包豪斯黄、功能蓝、珊瑚橙可作首屏装饰带；不得引入第四种颜色，也不得使用已退役的克莱因蓝。其他任何区域仍完全受 ADR-0012 约束。
5. **超大标题的内容是站点名**：`JELLYBIN` + 方括号副标 `[果冻盒]`；**这行文字就是首页的 `h1`**。原「JELLYBIN · 果冻盒」11px 小字降为普通文本（Q29"小字升 h1"方案被本条取代）。
6. **主旨句全删**：`BRAND.tagline`「一个会呼吸的个人博客」从页头 logo 旁、首屏大标题、页脚三处**全部移除**，并**从 `brand.ts` 删除该字段**（不留无消费点的死代码）。
7. **三格事实条删除**：首屏不再展示"置顶 / 本页最新 / 每页"，`homeHeroFacts()` 及其单测一并删除。
8. **满幅视觉来自运营上传的轮播图**：首张 `BannerItem.cover` 作满幅铺底；轮播控件（箭头 + 圆点）**并入首屏**并走 `--glass-thin`，≥2 张才显示控件；首屏下方不再出现独立轮播卡。
9. **动效**：色带、标题、图像分层做视差（上限 `--parallax-max` 10px）与滚动进场（位移 `--motion-reveal-offset` 12px），只动 `transform`/`opacity`，`prefers-reduced-motion` 下全部归零。仍受 ADR-0012 档位 C 约束。

## 理由与已否决方案

首屏是唯一需要"第一眼记住"的位置，而正因为它只出现一次、面积有限，才允许在这里破一次色彩纪律——这比"全站都是色带"安全得多，也比"全站都没颜色"更有记忆点。把例外写进独立 ADR 是为了让未来读者一眼看到"这是有意识的破例，不是漏删的残留"。

已否决的方案：

- **全站气质都转向瑞士/编辑部式**：等于推翻 ADR-0012 的中性立场与液态玻璃主线，且长文阅读页会被满幅图形打断；要推翻应另开 ADR 而非顺手扩大例外。
- **首屏 + 列表页都用色带**：列表页是重复刷新的信息面，色带会与内容卡片抢注意力，且色带语义（分区）在列表里没有对应意义。
- **保留人像/抠图**：没有人像素材；第三方插图涉及版权与风格不可控。
- **首屏只显示第一张轮播图、删掉其余**：运营已能上传多张，功能删掉但后台仍在配置 = 静默失效。
- **首屏自动轮播**：需要暂停控件、焦点管理、`prefers-reduced-motion` 与 `visibilitychange` 处理，无障碍成本高于收益。
- **把小字「JELLYBIN · 果冻盒」升为 h1**（Q29 的推荐）：在满幅版式里 h1 必须是视觉主体那行大字，否则语义与视觉主语不一致。
- **作为 ADR-0012 的追加条款**：0012 是全站通用规则，塞一个只适用于首屏的例外会削弱它的约束力。
- **只写进改造方案、不立 ADR**：这个例外没有决策记录，日后极易被当成"漏清理的残留色块"删掉。

## 代价 / 不做什么

- **例外区是色彩纪律的破口**：所有消费色带/刻度/记号的样式必须集中在一处（首屏封面组件）并在注释里写明"仅首屏"，否则会被复制到列表页。这条要靠评审与新增的设计测试守住。
- **窄屏是最危险的形态**：满幅 + 色带 + 超大黑体在手机上极易挤压文字。缓解：<768px 时色带减到 1 条、刻度与方括号记号隐藏、标题降到 `clamp(2rem, 9vw, 3rem)`。
- **首屏首屏渲染依赖 banner 接口**：轮播并入后，接口失败时封面没有图。缓解：沿用 `BannerCarousel` 现有的空态（`ProfileEmptyState`），并让色带 + 文字在没有图时仍成立（把图当"底"而不是"主体"）。
- **删 tagline 会让页脚少一行**：页脚版式需要重排（原来那行是 `AppFooter.vue:31`，样式 `:95`）。
- **三格事实删除后首页没有数据展示**：三个数字本是"站点还活着"的体感信号。缓解：不做替代展示，把"有内容"交给置顶/最新区块本身（这本来就是它们的作用）。
- **不做什么**：不做人像抠图与第三方插图、不做首屏自动轮播、不做超出三色的装饰、不做"色带"在其他页面的复用。

## 当前生效约束

1. 编辑部式版式（满幅色带、超大黑体、网格刻度、方括号/箭头记号）只允许出现在首页首屏封面区；任何其他页面或区块不得复用。
2. 首屏色带只可用包豪斯黄、功能蓝、珊瑚橙三色；不得引入第四种颜色，不得出现克莱因蓝。
3. 首屏是满幅的（脱离 `page-shell` 水平内边距），必须处理 `100vw` bleed 带来的横向滚动条。
4. 首屏视觉素材只来自运营上传的轮播图 `cover`；不得内嵌人像或第三方插图；无图时必须仍成立（色带 + 文字不依赖图）。
5. 首页 `h1` 是首屏超大标题（`JELLYBIN` + `[果冻盒]`）；不得退化为小字 h1，也不得出现"整页无 h1"。
6. `BRAND.tagline` 字段已删除；"一个会呼吸的个人博客"不得在任何页面重新引入。
7. 首屏不展示统计数据（三格事实条已删除），`homeHeroFacts()` 不得复活。
8. 轮播控件只在 ≥2 张时显示，走 `--glass-thin`；1 张或 0 张时不显示控件。
9. 首屏动效只动 `transform`/`opacity`，视差 ≤10px、位移 ≤12px，`prefers-reduced-motion` 下全部归零。
10. 窄屏（<768px）色带 ≤1 条、隐藏刻度与方括号记号，标题字号走 `clamp(2rem, 9vw, 3rem)`。
